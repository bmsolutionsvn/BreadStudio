# vMix screen reference

Screenshots of vMix Pro 26.0.0.45 x64, taken by the owner on 2026-10-14. They are the
target for BreadStudio's desk layout (S1) and later stages. Use them to place and size
things; do not copy vMix's icons, colours or artwork. BreadStudio keeps its own tally
colours (red Program, green Preview; S1 spec D6) and its own drawn AFV icon.

| File | Shows |
|---|---|
| `vmix-main-empty.png` | The main window with two Blank inputs. |
| `vmix-main-list-input.png` | A List input on Program, with its List tab docked on the right. |
| `vmix-main-audio-mixer.png` | The same, with the Audio Mixer tab open (Master, then one strip per input). |

Layout, top to bottom:

1. Top bar: Preset, New, Open, Save, Save As, Last (left); Fullscreen (centre); Pause
   Inputs, Basic, Settings (right).
2. Preview (orange title bar) on the left, Output (green title bar) on the right.
3. Between them a column of buttons: Quick Play, Cut, Fade, Merge, Wipe, CubeZoom, FTB,
   the four transition-effect slots 1 to 4, and the T-bar.
4. A strip with colour category tabs on the left and dock tabs (List, Audio Mixer) on the
   right.
5. The input bar: tiles with a title bar (number, name), a live picture, and two button
   rows (Close, Quick Play, Cut, Loop; 1 2 3 4 for the overlay channels, Audio, a monitor
   button, a gear). The docked tab opens to the right of the tiles.
6. Footer: Add Input, Record, External, Stream, MultiCorder, PlayList, each with a gear,
   and on the right Overlay and view buttons.
7. Status line: resolution and frame rate, FPS, render time, GPU memory, CPU.

Not yet in BreadStudio: the top bar, the Fade/Merge/Wipe button column, category tabs,
the overlay channels, the stats line.
